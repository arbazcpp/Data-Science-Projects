# Data Mining via Web Scraping

This project aims to utilize public data on a number of movies and their associated reviews through an API found at: https://www.gutenberg.org/browse/scores/top
This project demonstrates the ability to use BeautifulSoup, JSON data, API calls, and regular expressions.

## Table of Contents
- [Overview](#overview)
- [Installation](#installation)

## Overview
We utilize BeautifulSoup, the http://www.omdbapi.com API, and https://www.gutenberg.org/browse/scores/top to create a dataset that combines the identifying information about films and associated metadata, such as IMDB scores.
