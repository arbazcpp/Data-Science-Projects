# Aviation Delays

This project utilizes data from https://www.kaggle.com/datasets/sriharshaeedala/airline-delay in order to quantify the contributions of a variety of different delay categories to the total overall delay for a given flight.

## Table of Contents
- [Overview](#overview)
- [Installation](#installation)

## Overview
This project contains a dataset with each row containing data about the contribution to the overall delay due to a number of factors. We then utilize a RandomForestClassifier to find the most important features (or contributing factors) in terms of the overall delay for a given flight.
