# Image Recognition

This classic data science challenge utilizes the MNIST dataset, Tensorflow, and Keras, to create a machine learning application capable of recognizing a number displayed on an image based on its training.

## Table of Contents
- [Overview](#overview)
- [Installation](#installation)

## Overview
The dataset for this challenge is the MNIST dataset, a classic dataset with images of numbers typically utilized to train machine learning on pattern recognition. This data science challenge utilizes Tensorflow and Keras to create a machine learning application capable of recognizing a number displayed on an image based on its training.
