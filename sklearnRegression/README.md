# sklearnRegression

This project is my first experience using sklearn's KNN means classifier utilizing a dataset on housing prices.

## Table of Contents
- [Overview](#overview)
- [Installation](#installation)

## Overview
This project utilizes public data from the Bureau of Labour Statistics in order to compare KNN-means, logistic regression, and a random forest classifier on the accuracy of the model's prediction on housing prices from the given dataset. Our findings were that utilizing KNN-means with 8 neighbors resulted in the highest overall accuracy.
